## Sobre mí

Soy Técnico Universitario en Programación (UTN) y trabajo como desarrollador full stack, principalmente en el ecosistema TypeScript.

Lo que más disfruto es partir de un problema concreto y terminar con algo que alguien usa de verdad: una calculadora que trae los índices oficiales y hace la cuenta por vos, o un sistema de formularios para relevar información educativa de toda una provincia.

Me importa que el código quede ordenado: capas bien separadas, tests donde hacen falta y un README que explique cómo levantar el proyecto. También me gusta probar cosas nuevas; hoy trabajo con agentes de IA como parte de mi flujo de desarrollo, y por eso vas a ver archivos `CLAUDE.md` y `AGENTS.md` en algunos de mis repos.

Además, soy tutor de Java en la UTN.

## Proyectos destacados

### App Cálculo

Calculadoras para indicadores económicos argentinos con datos en vivo de BCRA, ArgentinaDatos y DolarAPI: cotizaciones del dólar con conversor, ajuste de alquileres por ICL o IPC, inflación acumulada y estimación de la primera cuota de créditos UVA.

La API propia guarda las series de índices en PostgreSQL (Supabase), las sincroniza con un cron diario y cachea las cotizaciones.

**En desarrollo:** gestión de contratos inmobiliarios.

`Next.js` `TypeScript` `Tailwind CSS` · `Express` `Prisma` `PostgreSQL` `Supabase` `Vitest`

[Ver demo](https://app-calculo-rho.vercel.app) · [Frontend](https://github.com/JeronimoCortez/app-calculo) · [API](https://github.com/JeronimoCortez/app-calculo-express)

### Relevamiento Provincial · DAE Mendoza

Sistema de formularios de relevamiento educativo que desarrollé en DAE Mendoza para los niveles primario, secundario y de adultos. Valida los datos con Zod y React Hook Form y envía las respuestas a Google Sheets a través de una única ruta de API.

`Next.js` `TypeScript` `Tailwind CSS` `Zod` `React Hook Form` `Google Sheets API`

[Ver sitio](https://formularios-relevamiento-dae.vercel.app) · [Repositorio](https://github.com/JeronimoCortez/formularios-relevamiento-dae)

### Sistema de reservas de hotel

API para gestionar habitaciones, usuarios y reservas (crear, confirmar y cancelar), con autenticación JWT y roles. La lógica de negocio vive en una capa de dominio separada del backend, siguiendo arquitectura limpia, y está cubierta con tests en Jest.

`Node.js` `TypeScript` `Express` `MongoDB` `Docker` `Jest`

[Repositorio](https://github.com/JeronimoCortez/hotel-reservations-for-it)

### E-commerce JEM

Tienda online completa. El backend en Spring Boot maneja usuarios con roles y JWT, productos, órdenes, descuentos programados, imágenes en Cloudinary y pagos con MercadoPago. El frontend en React incluye catálogo con filtros, carrito, checkout y panel de administración.

`Java` `Spring Boot` `MySQL` · `React` `TypeScript` `Vite` `Zustand`

[Backend](https://github.com/JeronimoCortez/ECommerceJemBack) · [Frontend](https://github.com/JeronimoCortez/ECommerceJemFront)
